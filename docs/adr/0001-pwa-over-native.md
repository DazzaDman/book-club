# Ship as a mobile-first PWA, not native apps

We need a mobile-first experience for a friends-and-family scale product without app-store overhead slowing iteration. We chose a responsive, mobile-first web app (PWA) over native iOS/Android apps, accepting weaker offline and push-notification support in exchange for faster iteration, no app-store review cycle, and a single codebase. A native shell can wrap the PWA later if distribution needs change.
